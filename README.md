# Spooky Bullet Hell

A dark survival bullet-hell game where your flashlight reveals danger.

## 🎮 Download and Play

### [Play in your browser on Unity Play](https://play.unity.com/en/games/ce46a556-ccce-41bd-86c3-461eddddf49c/dark-dodge-dave)

### [⬇ Download for Windows]
https://github.com/Ztaco10/Spooky_Bullet_Hell/releases/download/0.1.1/BulletHell-Windows-v0.1.1.zip 
1. Download the ZIP.
2. Right-click it and select **Extract All**.
3. Open the extracted folder and run the `.exe`.

**Keep all extracted files together.**

## Controls

- **WASD:** Move
- **Mouse:** Aim flashlight
- **Escape:** Pause

Survive as long as possible. Hold your flashlight on a ghost
for one continuous second to remove it.
